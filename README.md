# Davide Cavallaro Portfolio

Portfolio personale di **Davide Cavallaro**, Junior Full Stack Developer.

Il sito presenta profilo, competenze tecniche, progetti GitHub e contatti professionali in una landing page moderna, responsive e accessibile.

## Demo

Il progetto puo essere avviato localmente con Vite:

```bash
npm install
npm run dev
```

## Tech Stack

- React
- Vite
- Tailwind CSS
- Lucide React
- Framer Motion

## Funzionalita

- Layout responsive per mobile, tablet e desktop
- Navbar sticky con link a scorrimento fluido
- Hero section con foto profilo, bio e link rapidi
- Sezione competenze organizzata per categorie
- Card progetti generate dinamicamente da un file dati
- Sezione contatti con CTA professionale
- Dark mode toggle
- Pulsante scroll-to-top
- Animazioni leggere con Framer Motion
- Meta tag SEO e Open Graph
- UI pulita con tema chiaro e accenti blu

## Installazione

Clona la repository:

```bash
git clone https://github.com/maidire3/portfolio.git
cd portfolio
```

Installa le dipendenze:

```bash
npm install
```

Avvia il server di sviluppo:

```bash
npm run dev
```

Build di produzione:

```bash
npm run build
```

Anteprima della build:

```bash
npm run preview
```
